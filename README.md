# Agriculture × Water — editorial redesign

Open this folder in VS Code and use Live Server to preview index.html. Internet access is needed for fonts, the map library, map tiles, and background rivers and lakes.

Design: soft white paper, bold red type, thin rules, square slider handles, flat controls, a sticky map on desktop, and a map-first mobile layout.

All six agriculture layers, opacity settings, EPA overlays, and story markers preserve the original data and map interactions. Both waterway layers load automatically: nutrients in dark purple (#4b1f6f), pesticides in dark fuchsia (#8a1458). The legend matches the map. Both can still be toggled off independently. Detailed reading notes are expandable.

Edit index.html for layout and text, style.css for styling, and script.js for map behavior. The original Desktop project was not changed.
